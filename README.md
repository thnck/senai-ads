Este espaço funciona como um portfólio acadêmico, organizando conteúdos por semestre e por área de conhecimento, desde lógica de programação até banco de dados, requisitos, IoT e desenvolvimento web.

---

## 📘 Sobre o curso

O Curso Técnico em Desenvolvimento de Sistemas tem por objetivo habilitar profissionais para desenvolver, testar e implantar sistemas computacionais, atendendo às normas e padrões de qualidade, usabilidade, integridade e segurança da informação.

## 🎯 Perfil profissional

### Competência geral
Desenvolver, testar e implantar sistemas computacionais, atendendo normas e padrões de qualidade, usabilidade, integridade e segurança da informação.

### Função 1: Desenvolver sistemas computacionais
- realizar interação com banco de dados
- codificar programas
- programar sistemas com tecnologia IoT
- modelar sistemas
- manter sistemas computacionais

### Função 2: Testar sistemas computacionais
- elaborar cenários de testes
- executar plano de testes

### Função 3: Implantar sistemas computacionais
- validar a implantação de sistemas
- treinar usuários no sistema
