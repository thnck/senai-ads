# 🗄️ Banco de dados

Esta pasta contém exercícios de modelagem de banco de dados feitos no **brModelo**, além do programa necessário para abrir os arquivos de modelo.

## 🛠️ Requisitos

- Java instalado e configurado no `PATH`;
- brModelo, incluído neste diretório como `brModelo.jar`.

Confira o Java no terminal:

```bash
java -version
```

## ▶️ Como executar o brModelo

No PowerShell, a partir desta pasta, execute:

```powershell
java -jar .\brModelo.jar
```

Também é possível abrir o arquivo `brModelo.jar` com duplo clique, caso os arquivos `.jar` estejam associados ao Java no sistema.

## 📂 Como abrir os exercícios

1. Abra o brModelo.
2. Selecione `Arquivo > Abrir`.
3. Escolha um arquivo `.brM3` dentro de `modelagem-database`.
4. Edite ou consulte o modelo no programa.

## 📚 Conteúdo

- `modelagem-database/exerciciosModelagem`: exercícios de modelagem;
- `modelagem-database/desafioModelagem`: desafios de modelagem;
- `brModelo.jar`: programa usado para abrir e editar os arquivos `.brM3`.
