# ☕ Programação Orientada a Objetos — SENAI

Repositório com exercícios e projetos desenvolvidos durante os estudos de **Programação Orientada a Objetos (POO)** em Java no SENAI.

Cada pasta contém uma aplicação simples e independente, criada para praticar a modelagem de classes, atributos, métodos, encapsulamento e herança.

## 📚 Projetos

| Projeto | Tema | Conceitos praticados |
| :-- | :-- | :-- |
| [`prjPokemon`](./prjPokemon) | Personagens Pokémon | Classes, métodos e herança |
| [`prjNinja`](./prjNinja) | Ninja e chakra | Encapsulamento, getters e setters |
| [`prjNaruto`](./prjNaruto) | Informações de um ninja | Classes e objetos |
| [`prjBanco`](./prjBanco) | Conta bancária interativa | Encapsulamento, condições e `Scanner` |
| [`prjEmpresa`](./prjEmpresa) | Funcionários | Herança entre tipos de funcionário |
| [`lista02-poo/prjEx01Biblioteca`](./lista02-poo/prjEx01Biblioteca) | Biblioteca | Modelagem de livros e herança |

## 🧠 Conteúdos abordados

- Criação de classes e objetos
- Atributos e métodos
- Construtores
- Encapsulamento com `private`, getters e setters
- Herança e sobrescrita de métodos
- Estruturas condicionais
- Entrada de dados pelo terminal com `Scanner`

## 🛠️ Tecnologias

- Java
- IntelliJ IDEA

## ▶️ Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/thnck/POO-SENAI
   ```

2. Abra o projeto desejado no IntelliJ IDEA.
3. Localize a classe `Main.java` (ou `MenuApp.java`, no projeto do banco).
4. Execute o método `main` pela IDE.

> Cada pasta é um exercício independente. Abra e execute um projeto por vez.
