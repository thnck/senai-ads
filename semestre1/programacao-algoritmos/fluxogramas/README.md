# 🔀 Fluxogramas

Esta pasta contém fluxogramas dos exercícios de algoritmos nos arquivos `.fprg`.

## 📦 Programa necessário

Use o **Flowgorithm**, programa compatível com arquivos `.fprg`. Faça o download pelo site oficial:

<https://www.flowgorithm.org/download/index.html>

## ▶️ Como abrir e executar

1. Instale e abra o Flowgorithm.
2. Selecione `File > Open`.
3. Escolha um arquivo `.fprg` em `fluxoAlgoritmos` ou `fluxogramaEmerson`.
4. Use `Run` para executar o fluxograma.
5. Quando o algoritmo solicitar valores, informe-os na janela de entrada.

Também é possível abrir um arquivo `.fprg` diretamente pelo Explorador de Arquivos depois de associá-lo ao Flowgorithm.

## 📚 Conteúdo

- `fluxoAlgoritmos`: fluxogramas identificados como `fx01` até `fx06`;
- `fluxogramaEmerson`: exercícios identificados como `ex01_fluxograma` até `ex08_fluxograma`.
